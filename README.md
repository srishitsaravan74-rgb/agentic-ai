An Agentic AI application built using Agno that demonstrates how AI agents can reason, use tools, process information, and perform tasks autonomously.

The project is designed to explore the fundamentals of AI Agents, Agentic AI, LLMs, tool calling, and intelligent task execution using Python and Agno.

🚀 Features
🤖 AI Agent powered by Agno
🧠 LLM-based reasoning and response generation
🛠️ Tool integration for performing external tasks
💬 Natural-language interaction
🔄 Agentic workflow for completing user tasks
⚡ Fast and lightweight Python implementation
🔐 API key support through environment variables
📦 Simple project structure for easy customization
